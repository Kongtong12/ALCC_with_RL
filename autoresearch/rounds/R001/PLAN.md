# R001：理论路线与计算价值筛选

状态：**草案，未冻结，未执行**。这是下一轮工作单，不是已完成的研究报告。计划用第一周回答是否值得继续投入证书复用主线。

## 中心问题

在固定可行域、动态优先级下，非精确旧解的证书是否具有超出已有结论的算法价值，并能减少候选指派比较的实际计算？

## 原型要求

先选可精确核验的凹分配实例。固定容量时分别改变参数漂移幅度、稀疏度、候选复用率、离切换阈值的距离；容量变化作为独立压力情形，不偷用固定域保证。加入冷启动、边界解和几乎无切换收益的情形。

运行前冻结实际范围、硬件、精度、随机种子、重复方式、计时方法、成本上限与判定阈值。原型 pilot 可以探索，但结果只能叫开发证据。此草案不设事后可移动的“显著加速”阈值；具体数值需按应用需求和短校准在观测比较结果前写入子协议。

记录至少：决策与精确 oracle 是否一致、可行性违反、效用差距、证书宽度、接受／拒绝／继续计算次数、内层求解次数、缓存命中、检查时间、总墙钟、执行分配成本、切换成本和失败回执。证书越界必须先区分数学错误、求解误差与数值容差，再修正规则并重新验证。

## 决策标准

- **继续**：在最接近结果之外有清楚的增量；条件不是为排除所有难例而设；最小实验显示有希望在公平强基线下节约总计算；可以给出一个明确算法而非只列性质。
- **缩小**：数学成立但只是标准推论，或只在稀疏变化／高复用情形有用。转为条件清楚的应用算法贡献，不再以广泛新理论为标题。
- **停止该主线**：核心证书在所需设定不成立且修正后无用；强基线直接覆盖；或完整计账后没有可解释的计算价值。

若停止，回到当前稿件的正确性修正、共享容量分配、实现对齐和公平实验，不以启动更多无关方向抵消失败。
